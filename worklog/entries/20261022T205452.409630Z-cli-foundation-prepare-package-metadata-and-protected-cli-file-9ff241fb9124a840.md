# Prepare package metadata and protected CLI file boundaries

## Summary

Prepared an independently testable prerequisite for CLI delivery while the remediation backend and persistent lifecycle workers implement their disjoint files. This unit does not implement or verify the complete CLI, and the delivery checklist remains open for user-facing execution.

## Changes

- Added `pyproject.toml` with pinned build backend `setuptools==83.0.0`, no runtime dependencies, and Python 3.12 support. Other interpreter versions are not declared supported until the private HTTP response hook and process controls are verified there. Console entry point and README metadata will be added with the actual CLI.
- Added `autoprotect/local_files.py` with bounded regular-file reads, descriptor-relative no-follow directory traversal, private policy ownership/mode checks, effective-root requirement for live mode, and protected SQLite directory/database/sidecar handling. Existing permissions and contents are never repaired or replaced. The invoking user and root remain trusted; metadata checks detect observed concurrent writes, not malicious-owner snapshots.
- Added `tests/test_local_files.py` using disposable files only. Shared `docs/DESIGN.md` now states the local-file boundary and explicit Engine return/Simulator setup contracts, so parallel implementations and later CLI integration agree without editing one another's files.

## Validation

- Red-first `python3 -m unittest discover -s tests -p 'test_local_files.py' -v` failed because the required module did not exist. After implementation all 15 tests passed in 0.004 seconds. Coverage includes byte caps, private modes, symlink components, hardlinks, FIFOs, public ancestors, no permission repair, private idempotent database creation, unsafe sidecars, changed reads and effective-root denial.

Installed the wheel into a fresh temporary virtual environment using `python3 -m pip --python VENV/bin/python install --no-index --no-deps WHEEL`. From outside the repository, isolated Python imports, package version and public pwn parser passed. No network or host-environment install occurred. Final integrated packaging will be checked again after CLI/backends land.

Independent re-review confirmed closure with five additional temporary-directory tests exercising both APIs and absolute/relative, single/multiple-parent traversal; no remaining concrete finding was reported.
