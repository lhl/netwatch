# Implement bounded pwn and Debian feed adapters

## Summary

Implemented the assigned pwn.watch and Debian adapter unit without changing shared runtime, documentation or inventory files. The four public function signatures and normalized output keys are unchanged. Parsers retain bounded untrusted evidence; fetching never follows feed links or accepts arbitrary endpoints. All 26 feed tests and the current 109-test repository suite passed.

A full public Debian smoke fetch exposed a contract gap: 797 of 77,341 assertions use Debian TEMP identifiers, not CVEs. The adapter retains well-formed TEMP identifiers with status=unknown, including records reporting fixed_version="0". The integration owner must widen the documented ID contract and coordinate matching validation before closing the integrated feed-to-finding requirement. No CVE identities are invented, and temporary records are not silently discarded.

## Changes

- Added `autoprotect/feeds.py` with `parse_pwn(data)`, `parse_debian(data, release="trixie")`, `parse_source(source, raw)` and `fetch_source(source, etag=None)`. Only trixie is supported. Missing release evidence, incomplete fixes, conflicting open/fixed assertions and unsupported fixed-version syntax remain unknown; unknown publisher states remain visible.
- Added `tests/test_feeds.py` and synthetic `tests/fixtures/feeds/pwn.json` / `debian.json`. Coverage includes actual observed envelope/nesting shapes, CVE/GHSA/MAL identifiers, temporary Debian identifiers, duplicate/malformed/oversized inputs, examples, hostile/control text, spoofed provenance, special zero fixes, HTTP statuses, conditional validators and resource bounds.
- pwn output keys: `id`, `title`, `summary`, `identifiers`, `severity`, `patch_status`, `product`, `updated_at`, `is_example`, `affected_versions`, `fixed_versions`. Informational version lists and publisher timestamp text are not interpreted as package targets or acquisition times.
- Debian output keys: `id`, `source_name`, `release`, `status`, `fixed_version`, `urgency`, `description`. Example: `{id: CVE-2026-10001, source_name: example-source, release: trixie, status: resolved, fixed_version: 1:1.0-1+deb13u2, urgency: high, description: synthetic text}`. Ordinary resolved entries still require installed-version comparison downstream.
- Transport returns `{not_modified, raw, etag}` with bytes for a 200 and `raw=None` for a 304. It attaches no acquisition trust or freshness. Fixed direct HTTPS connections use certificate/hostname verification and identity encoding; environment proxies, redirects and compression are not used. Limits are 8 MiB for pwn, 128 MiB for Debian, 10 seconds per socket operation, and a 60-second isolated-process deadline covering DNS and response handling. Timeout cleanup permits two additional 0.25-second process joins. Partial bodies never escape on failure.
- Parser limits include 32 nesting levels, 8,000,000 nodes, bounded strings including ignored fields, 10,000 pwn incidents, 500,000 Debian assertions and 256 elements per informational/identifier list. Duplicate incident identities and duplicate JSON keys reject the complete snapshot; repeated identifiers within one incident are deduplicated.
- Test injection: replace private `_CONNECTION_FACTORY` with a picklable HTTPSConnection-compatible factory for public `fetch_source` tests. Private `_fetch_http(source, etag, output, *, connection_factory, clock, max_bytes, timeout)` supports an in-memory binary sink and deterministic fake clock/transport. No CLI transport override is provided.

- `python3 -m unittest discover -s tests -v`: 109 tests passed in 5.766 seconds against the shared working tree at verification time. Other workers' tests were included; this is not an integrated CLI/backend acceptance claim.
- `python3 scripts/worklog.py check`: passed for the three indexed entries. `python3 scripts/worklog.py render`: rendered three committed entries. This new handoff entry is deliberately unstaged and therefore outside the index check; the parent must stage exact reviewed paths and rerun it.
- `git diff --check`: passed. An additional Python wrapper ran `git diff --no-index --check -- /dev/null PATH` for all four new owned implementation/test/fixture paths and confirmed empty diagnostics (exit 1 denotes a new-file diff, not whitespace failure). No staging or commits were performed.
- Bounded public pwn smoke command: `python3 -c 'from autoprotect.feeds import fetch_source, parse_source; result=fetch_source("pwn"); print({"source":"pwn", "not_modified":result["not_modified"], "bytes":len(result["raw"]), "etag_present":result["etag"] is not None}, flush=True); print({"normalized_records":len(parse_source("pwn", result["raw"]))})'`. Result: 200, 943,177 bytes, ETag present, 719 normalized incidents.
- Bounded public Debian smoke command: `python3 -c 'from autoprotect.feeds import fetch_source, parse_source; result=fetch_source("debian"); print({"source":"debian", "not_modified":result["not_modified"], "bytes":len(result["raw"]), "etag_present":result["etag"] is not None}, flush=True); rows=parse_source("debian", result["raw"]); print({"normalized_records":len(rows), "temporary_unknown_records":sum(row["id"].startswith("TEMP-") and row["status"] == "unknown" for row in rows)})'`. Result: 200, 85,767,615 bytes, no ETag, 77,341 normalized assertions including 797 unknown temporary assertions. An earlier diagnostic counted 4,112 source packages. No downloaded corpus was retained in Git.
- Initial smoke requests exposed an HTTPResponse socket-lifetime bug after complete Content-Length consumption. Fixed the extra socket operation and added local socket-pair tests using the real standard-library HTTPResponse for content-length, zero-length, chunked and close-delimited responses. Repeated bounded smoke requests then succeeded. The initial Debian parser rejection of TEMP records was also resolved and covered by a synthetic regression test.
- Deterministic tests exercise public fetch success/error/304 paths through real spawned workers with fake connections, plus stalled connect/header/body phases. No live conditional 304 was rechecked in this unit. No private inventory, package changes, credentials, live remediation or external publication was involved.
